# Preguntas frecuentes de UESAN Shopping

## ¿Puedo cambiar la dirección de entrega?
Sí, mientras el pedido esté en estado PENDIENTE. Una vez ENVIADO ya no se puede modificar.

## ¿Cómo sé si un producto tiene stock?
La página de cada producto muestra el stock disponible. Si el stock es cero, el producto no se puede comprar.

## ¿Atienden reclamos por el Libro de Reclamaciones?
Sí. El Libro de Reclamaciones virtual está disponible en la web y se responde en un plazo máximo de 15 días hábiles.
